# Pegwork

A pixel-art gambling roguelike where you build the marble machine you gamble on.

**Play the current build:** https://ycgnem.github.io/pegwork/

Right now this is Milestone 0: the base board and its physics. Click a column on the rail to drop
a marble; the Dry Run beside the board shows what that column pays per $1 staked, with its
margin of error, over 300 simulated drops.

TypeScript + Vite, one 384x216 Canvas 2D, our own deterministic circle physics. `npm install`,
`npm run dev`, `npm test`. Design docs: `PLAN.md`, `DESIGN.md`, `STYLE.md`, `ROADMAP.md`.

No real money, ever.
